# Memoria Viva — Caso 10

Aplicación web académica para analizar el caso de las familias de digitalización.

## Archivos

- [Aplicación web](./Memoria_Viva_Caso_10.html)
- [Transcripción de la resolución](./Caso_10_resolucion_transcripcion.md)

## Cómo abrir la aplicación

1. Descarga `Memoria_Viva_Caso_10.html`.
2. Ábrelo con Chrome, Edge o Firefox.
3. Ajusta demanda, minutos, mezcla, presupuesto y método.
4. Exporta las tablas a CSV compatible con Excel o usa la opción de imprimir para generar PDF.

## Nota sobre el documento fuente

La resolución se añadió como transcripción en Markdown a partir del texto extraído del archivo Word. El archivo binario original `Caso 10.docx` no se ha reemplazado ni modificado localmente; esta integración de GitHub no permite adjuntar directamente ese DOCX binario mediante la acción de creación de archivos de texto. Algunas fórmulas o elementos gráficos pueden requerir cotejo con el Word original.
